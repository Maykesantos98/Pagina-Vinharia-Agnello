# Vinharia Agnello

Landing page responsiva de uma vinícola da Serra Gaúcha, com experiência editorial premium, catálogo de vinhos e checkout pelo WhatsApp.

## Recursos

- Layout responsivo para desktop, tablet e celular
- Menu mobile acessível
- Catálogo com três rótulos
- Sacola persistente com quantidades, remoção e subtotal
- Checkout com pedido preenchido no WhatsApp
- Newsletter com validação
- SEO, metadados sociais e suporte a movimento reduzido
- Testes estruturais e fluxo E2E em navegador real

## Executar localmente

Requer Node.js 18 ou superior.

```bash
npm start
```

Acesse `http://127.0.0.1:4173`.

## Testes

```bash
npm test
```
